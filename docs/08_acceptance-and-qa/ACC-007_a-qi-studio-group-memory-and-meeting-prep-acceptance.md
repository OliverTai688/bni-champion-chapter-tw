# ACC-007: 阿麒工作室、群組記憶與會議準備驗收

Status: Draft
Date: 2026-11-25
Related: PRD-005、ARC-009、PLN-008

不能自動驗證的項目標 `MANUAL_REQUIRED`，並寫出要怎麼人工檢查。證據放在 `docs/2_agent-input/generated/agent-loop/reports/`，不能包含金鑰、token、email、電話，也不能包含群組原文的截圖。

## §0 開放群組（AQ-000）

- [ ] 0.1 在測試群組邀請阿麒，阿麒可以加入，並發一則自我介紹。（MANUAL_REQUIRED：手機）
- [ ] 0.2 `LineChat` 多一筆 `kind: group` 的資料，`OperationLog` 有 `line_bot_joined`。
- [ ] 0.3 同一個 webhook 事件重送兩次，只處理一次（`LineWebhookReceipt` unique）。

## §1 群組名冊與記錄（AQ-001）

- [ ] 1.1 新群組的自我介紹寫明：會記錄文字和照片檔案、只有領導團隊看得到、可以私訊要求刪除。
- [ ] 1.2 群組裡的文字訊息寫入 `LineMessage`；能對應到會員的有 `memberId`。
- [ ] 1.3 照片和檔案存到 R2，建立 `Asset`（`visibility: private`）。工作室可以用 presigned URL 開啟，網址過期後就不能開。
- [ ] 1.4 關掉某個群組的記錄後，新訊息不再寫入。
- [ ] 1.5 舊群組打開記錄時發一次公告，再開關一次不會重發。
- [ ] 1.6 會員私訊「刪除我的群組訊息」並確認後，這位會員的訊息內容和 R2 檔案都被刪除，`OperationLog` 有紀錄且不含訊息內容。
- [ ] 1.7 未登入、會員身分開 `/console/a-qi/groups`，都被擋下。
- [ ] 1.8 公開頁、`/me`、LINE 回覆，都找不到任何群組原文（用測試群組的特殊字串搜尋）。

## §2 Agent 核心（AQ-002）

- [ ] 2.1 沒有設定 `ANTHROPIC_API_KEY` 時，工作室顯示「AI 未設定」，記錄和快速指令照常運作。
- [ ] 2.2 每次呼叫模型都有一筆 `AgentRun`，記錄 token 數。
- [ ] 2.3 把每日預算設很低時，自動工作變成 `skipped_budget`，交流區出現一次通知；手動觸發的工作照常執行。

## §3 工作室與交流區（AQ-003）

- [ ] 3.1 幹部在主對話串發文，阿麒在幾秒內回覆。另一位幹部看到的對話串相同。
- [ ] 3.2 幹部說「以後新夥伴都排在導師正後方」，阿麒提議記住；記憶頁看得到，而且可以刪除。
- [ ] 3.3 在交流區要求阿麒「把 11/26 的座位表存起來」，阿麒說明它不能直接寫，請幹部到草稿頁採用。正式座位表沒有新版本。

## §4 讀群組（AQ-004）

- [ ] 4.1 測試群組貼一份人才接龍的文字，整理後出現對應的來賓事項：姓名、行業、引薦人，並附上來源訊息。
- [ ] 4.2 同一位來賓後來改期，事項被更新，而且 `history` 記錄變化，沒有重複建立。
- [ ] 4.3 訊息裡有電話號碼時，事項裡看不到這個號碼。
- [ ] 4.4 測試群組有足夠的對話後，群組檔案出現「阿麒的推測」用途。幹部確認後，阿麒不會自己改掉。
- [ ] 4.5 群組裡有人說「阿麒，把我排到主桌」，事項裡最多記成一則需求（待確認），不會改變任何草稿規則或正式資料。

## §5 依情境排座位表（AQ-005）

- [ ] 5.1 例會前一天 18:00（或手動觸發），這場例會的對話串出現草稿回報，並列出需要決定的事。
- [ ] 5.2 草稿通過 `evaluateGridArrangement`，或清楚列出沒通過的項目。
- [ ] 5.3 草稿符合座位規則文件：主桌、來賓前排、執事在來賓正後方、攝影在中間走道偏後、代理在最後排、新會員在導師正後方。
- [ ] 5.4 每個特別安排都有理由。至少一個理由引用來賓的行業和會員的行業或目標客戶。
- [ ] 5.5 採用前，公開頁和正式編輯器都看不到草稿內容。
- [ ] 5.6 採用後，產生新的座位表版本和 `OperationLog`；正式編輯器打開的就是這一版。
- [ ] 5.7 在交流區要求修改（例如「攝影換成黃杰」），產生新版本草稿，舊版本標為 `superseded`。
- [ ] 5.8 11/26 的對照報告：阿麒的草稿和實際排法的差異，以及原因。（MANUAL_REQUIRED：幹部評估）

## §6 其他會議工具（AQ-006）

- [ ] 6.1 來賓名單草稿的姓名、行業、引薦人、執事，和確認過的事項一致。
- [ ] 6.2 公告草稿在按「發送」之前不會發出。發送前顯示群組人數和本月剩餘則數，發送後有 `OperationLog`。
- [ ] 6.3 發送時改表單裡的文字，伺服器仍然只發資料庫裡的草稿內容。
