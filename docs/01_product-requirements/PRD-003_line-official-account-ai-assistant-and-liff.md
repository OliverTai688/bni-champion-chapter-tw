# PRD-003: 長冠軍同行者 助理、LINE 官方帳號與 LIFF 網站

Status: Draft
Date: 2026-11-18
Related: ARC-008、PLN-007、ACC-006、PRD-001、ACC-005

## 目的

讓分會夥伴在 LINE 裡就能用到這個網站，不用另外開瀏覽器、不用記網址：

1. 網站有一個「長冠軍同行者」，可以在網站上對話，也可以在 LINE 官方帳號裡對話。兩邊是同一個 AI 的兩個入口。
2. 簽到、查座位、抽獎、投票、問問題，都到官方帳號的**一對一聊天**裡做。
3. 官方帳號也加進分會群組，但在群組裡**保持安靜、友善**，不刷屏。它在背景把群組資料收回網站。
4. 整個網站包成 LIFF 頁面，在 LINE 裡打開就不用跳出去，也能**直接用 LINE 身分登入**。

## 產品原則

| 原則 | 說明 |
| --- | --- |
| 群組不刷屏 | AI 在群組只在被 @ 時回應，而且只回一句短的話或一個連結。不主動聊天，也不逐則回覆。 |
| 事情在一對一做 | 簽到、查自己的座位、問問題都在一對一聊天裡做。一對一回覆不用推播則數，也不會讓別人看到個人資料。 |
| 網站是主體 | 能在網頁做的，就讓 LINE 打開網頁（LIFF），不在聊天裡重做一套介面。聊天只做「打一句話就能完成」的事。 |
| 身分來自 LINE，不來自訊息內容 | 誰在說話，由 LINE 提供的 userId 和 `MemberIdentity` 決定。AI 不能因為訊息裡寫「我是某某」就把對方當成那個人。 |
| 寫入權限最小化 | 在 LINE 裡，AI 只能幫「說話的本人」簽到。改座位、建活動、發公告這些動作，只在網站後台由領導團隊操作。 |
| 公開資料規則不變 | 沿用 AGENTS.md 的隱私規則。群組裡有來賓，群組回覆只能出現公開等級的資訊。 |

## 使用者與入口

| 角色 | 主要入口 | 能做的事 |
| --- | --- | --- |
| 會員 | 官方帳號一對一聊天、圖文選單、LIFF 網頁 | 簽到、看今日座位、抽獎、投票、看自己的出席、問 AI |
| 來賓／還沒綁定的 LINE 使用者 | 官方帳號一對一聊天、LIFF 網頁 | 看公開的活動頁、問一般問題、拿到綁定或請幹部協助的說明 |
| 領導團隊 | 網站 `/console`、網站 AI 頁、LIFF 網頁 | 原有的後台功能，加上網站 AI 對話（可用排座工具）、群組資料瀏覽 |
| 分會群組 | 官方帳號被加入的群組 | 被 @ 時拿到短回覆或連結；會員可以從 LIFF 把座位表卡片分享到群組 |

## 需求

### R1. LIFF 網站與 LINE 內登入

- R1.1 在 LINE 裡打開網站任一頁（活動頁、簽到、抽獎、投票、`/me`）都不跳出 LINE。
- R1.2 在 LINE 裡打開時自動用 LINE 身分登入，不用按登入按鈕。已綁定的會員直接是登入狀態，跟用 LINE Login 登入的結果相同。
- R1.3 還沒綁定的 LINE 使用者，看到的是現有的「第一次 LINE 登入選姓名」流程。
- R1.4 **領導團隊在 LINE 裡用共用密碼進 `/console`**（沿用 `ADMIN_PASSWORD`）。Google 不允許在 App 內建瀏覽器登入，所以在 LINE 裡不提供 Google 登入，改顯示「請用密碼，或改用一般瀏覽器開啟」。
  - 密碼值只設在正式環境的環境變數，不寫進文件、程式碼或聊天紀錄。
  - 有現任幹部任期、而且已綁定 LINE 的人，本來就是領導團隊（ACC-005），不需要另外輸入密碼。
- R1.5 一般瀏覽器的登入方式（Google、LINE Login、一次性登入連結、密碼）維持不變。

### R2. 圖文選單

- R2.1 官方帳號一對一聊天室底下有固定的圖文選單，預設六格：**簽到、今日座位、抽獎、投票、我的、問 AI**。
- R2.2 「簽到」「今日座位」「抽獎」「投票」「我的」都打開對應的 LIFF 網頁。「問 AI」提示使用者直接打字提問。
- R2.3 今天沒有活動時，打開頁面要顯示清楚的空狀態，例如「今天沒有例會，下一場是 11/27（四）」，不能出現錯誤頁。

### R3. 一對一聊天的快速指令

不經過 AI 模型，直接比對關鍵字，回覆快、結果固定、不花模型費用。

| 使用者輸入 | 回覆 |
| --- | --- |
| `簽到` | 已綁定的會員：幫本人簽今天的例會，回「✅ 王小明 已簽到，座位 B3」。遲到就照現有規則記成遲到。已經簽過的回「已經簽到過了」。沒綁定的回綁定連結。今天沒有活動就說下一場的日期。 |
| `座位`、`座位表` | 今日活動頁的 LIFF 連結，已綁定的會員附上自己的座位。 |
| `抽獎` | 今日抽獎頁的 LIFF 連結。 |
| `投票` | 今日投票頁的 LIFF 連結（有開放中的投票時）。 |
| `說明`、`help` | 列出可以用的指令和圖文選單的用法。 |

其他文字交給 R5 的 AI 對話處理。

### R4. 群組裡的行為

- R4.1 被加入群組時，發一則**一次性**自我介紹，說明：它會做什麼、它會記錄群組訊息（R6 開啟時）、怎麼私訊它。
- R4.2 平常完全不發言。
- R4.3 被 @ 時才回應，回覆限一則、簡短。能用連結解決的就給連結，例如「座位表在這裡 👉」。需要個人資料的問題，請對方私訊。
- R4.4 有人在群組打「簽到」時，回一則「請點這裡簽到 👉 LIFF 連結」，同一場活動在同一個群組最多提醒一次，不逐人回覆。
- R4.5 從 LIFF 活動頁提供「分享到群組」按鈕（LINE 的分享選擇器），由會員或幹部本人把座位表、抽獎卡片分享到群組。這是以本人名義發送，不是官方帳號的推播。

### R5. 長冠軍同行者 對話

- R5.1 模型供應商可以設定成 Claude 或 OpenAI。金鑰只放在伺服器的環境變數，網站任何頁面都不顯示金鑰。
- R5.2 網站入口：`/console/agent`，給領導團隊使用。可以用現有的排座工具（`src/server/ai/seating-service.ts`）：查活動、看座位、評估排法、存座位表。寫入一律建立新的座位表版本並記錄操作紀錄（沿用 AGENTS.md 的規則）。
- R5.3 LINE 一對一入口：會員和來賓都可以問問題。能用的工具依身分限制：
  - 公開：今日或下一場活動的時間地點、公開座位表連結、抽獎和投票連結、例會流程、分會常見問題。
  - 已綁定的會員，再加上：自己的座位、幫自己簽到、自己的出席紀錄。
- R5.4 群組入口：只用公開等級的工具，回覆受 R4 限制。
- R5.5 AI 回答不了或不確定的時候，要說不知道，並請對方聯絡幹部，不能編造。
- R5.6 每個使用者每天的 AI 對話次數有上限（預設 30 次），避免費用失控。超過時回覆固定訊息。
- R5.7 對話紀錄保存一段時間（預設 90 天），用來讓 AI 記得上下文和讓幹部除錯，期限到了自動刪除。

### R6. 群組資料收集（可關閉）

- R6.1 每個群組可以在後台個別開關「記錄訊息」，預設關閉。
- R6.2 開啟後，文字訊息存 MongoDB。照片、影片、檔案、語音下載後存 Cloudflare R2，MongoDB 只記檔案位置和中繼資料。
- R6.3 能對應到會員的發言者，記錄會員 id；對應不到的只記 LINE userId 和顯示名稱。
- R6.4 只有領導團隊能在後台瀏覽和搜尋，公開頁、會員頁都看不到。
- R6.5 有保存期限（預設 365 天），到期刪除，包含 R2 檔案。
- R6.6 只收得到官方帳號加入群組**之後**的訊息，之前的歷史拿不到。

### R7. 定時推播（選用，最後做）

- R7.1 例會當天早上，可以選擇把今日座位表卡片推播到指定群組。
- R7.2 推播會用到官方帳號的每月則數，而且群組推播是按群組人數計算。後台要顯示本月已用和剩下的則數，預設每週最多一則。

## 不做的事（這個階段）

- 不在 LINE 聊天裡做座位編輯、活動建立、名單管理。
- 不讓 AI 在群組裡主動發言或逐則回應。
- 不讀取官方帳號加入群組之前的歷史訊息。
- 不支援 Google 在 LINE 內建瀏覽器登入（Google 本身不允許）。
- 不讓使用者自己填 API 金鑰，金鑰由擁有者設在伺服器。

## 成功指標

- 例會當天用 LINE 簽到（聊天指令或 LIFF）的比例，超過全部簽到的一半。
- 群組裡由官方帳號發出的訊息，每週不超過 3 則（不含自我介紹）。
- AI 對話「答不出來」的比例，隨常見問題補齊逐週下降。
- 推播則數不超出官方帳號方案的額度。

已決定（2026-11-25）：

- Q2：AI 預設用 Claude。
- Q3、Q4 的群組部分：文字、照片、檔案全部記錄，不設保存期限，加入群組時公告。R6.1 的「預設關閉」和 R6.5 的 365 天，改由 PRD-005 R2 取代。一對一對話的保存期限（R5.7）仍是預設的 90 天。
- 群組了解、阿麒工作室、依情境排座位表的需求，見 PRD-005。

已決定（2026-11-18）：

- AI 的角色是麒麟「阿麒 A-Qi」，定位為「長冠軍商會的 AI 同行夥伴」（原暫定名「長冠軍同行者」）。LINE Login channel 名稱已改為「阿麒」，人格、說話方式和視覺規範見 PRD-004。
- 原本的 Q1 已解決：正式網站原本只開 Google 登入，沒有任何會員綁過 LINE。所有 LINE 設定統一放在新建的 Provider「BNI 長冠軍分會」底下：網站 LINE 登入、LIFF app、官方帳號。這樣三邊拿到的 userId 都相同。

- 簽到和互動都在官方帳號一對一聊天裡做，群組保持安靜（R3、R4）。
- 網站包成 LIFF，在 LINE 裡自動用 LINE 身分登入（R1）。
- 領導團隊在 LINE 裡用共用密碼進後台（R1.4）。
